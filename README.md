
# Sistema de Gestión de Pedidos e Inventario

## Descripción
Proyecto integrador desarrollado con Java y Spring Boot/Jakarta EE, orientado a la gestión de pedidos y al control de inventario mediante servicios independientes.

## Estructura del proyecto

### 1. inventario-service
Servicio encargado de administrar los productos y el stock disponible.

### 2. sistema-pedidos-springboot
Aplicación encargada de gestionar los pedidos e interactuar con el servicio de inventario.

## Tecnologías utilizadas
- Java
- Spring Boot
- Jakarta EE
- Maven
- JPA / Hibernate
- REST API
- Base de datos

## Instalación y ejecución
Cada proyecto contiene su propio archivo `pom.xml`.
Abrir cada módulo en IntelliJ IDEA, configurar sus dependencias y ejecutar la aplicación correspondiente.
